# YOconlang: Numerals and Mathematical Block (OO / V, VV)

This file defines the system of numbers, scale exponents, and math routing operations within the YOconlang ecosystem.

---

## 🟩 ABSOLUTE SYSTEM MARKERS (V / VV)

* `U` or `UU` — Absolute markers of negation, zeroing, annihilation, and destructive aspect.
* `E` or `EE` — Absolute markers of interrogation, parameter query, uncertainty, and information search.
* `O` or `OO` — **Absolute mathematical system marker**. It shifts the grammatical system into numerals and arithmetic operations mode. It functions as a strictly isolated mathematical grammar tool.

## 🟩 EXPONENTIAL & DECIMAL SCALE PARTICLES

Scale modifiers handle mathematical magnitude using base-10 exponents ($10^x$) and direct the balance point for fractional operations:

| Particle | Math Meaning | Power | US English Description |
| :--- | :--- | :--- | :--- |
| **sa** | $\times 10^1$ | $10^1$ | Tens digit scaling multiplier (e.g., 20, 30). |
| **se** | $\times 10^2$ | $10^2$ | Hundreds digit scaling multiplier (e.g., 200, 300). |
| **su** | $\times 10^3$ | $10^3$ | Thousands digit scaling multiplier (e.g., 4,000, 5,000). |
| **si** | $\times 10^6$ | $10^6$ | Millions digit scaling multiplier (e.g., 1,000,000). |
| **so** | Decimal point | $10^{-x}$ | The baseline balance marker for decimal fractions. |
