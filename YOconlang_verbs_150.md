# YOconlang Core Vocabulary: Verbs (150 roots)
# Базовый словарь YOconlang: глаголы (150 корней)

> **Status / Статус:** proposal, pre-1.0. / предложение, версия до 1.0.
> The roots are generated by the three-axis matrix of the README; no separate meaning table for the 605 `CVC` coordinates exists, so this list is the first population of the matrix. / Корни построены по трём осям матрицы из README; отдельной таблицы значений для 605 координат `CVC` нет, поэтому этот список является первым наполнением матрицы.

## 1. Template and axes / Шаблон и оси

**EN.** A verb root is `C₁ V C₂`: **domain** (where the action comes from) + **process** (how it acts) + **target** (what it acts upon). Roots are immutable: tense, aspect and modality are expressed by particles (CV, VV).
**RU.** Корень глагола имеет вид `C₁ V C₂`: **домен** (откуда исходит действие) + **процесс** (как оно действует) + **цель** (на что направлено). Корни неизменяемы: время, вид и модальность выражаются частицами (CV, VV).

| Letter | Domain `C₁` / Домен | Target `C₂` / Цель |
|:---:|---|---|
| `l` | Space / Пространство | Location, point / Место, точка |
| `t` | Time / Время | Term, event / Срок, событие |
| `p` | Inanimate matter / Неживая материя | Object, instrument / Предмет, орудие |
| `b` | Energy and forces / Энергия и силы | Element, directed force / Элемент, направленная сила |
| `s` | Biosphere, life / Биосфера, жизнь | Bio-object, organism / Организм |
| `n` | Psyche, will / Психика, воля | Personality, mental state / Личность, душевное состояние |
| `v` | Primary perception / Первичное восприятие | Primary sensation / Первичное ощущение |
| `m` | Language, signs / Язык, знаки | Word, concept / Слово, понятие |
| `k` | Data, memory / Данные, память | Message, text / Сообщение, текст |
| `h` | Thinking, algorithms / Мышление, алгоритмы | Rule, algorithm / Правило, алгоритм |
| `j` | Social sphere / Общество | Collective, network / Коллектив, сеть |

| Process `V` / Процесс | English | Русский |
|:---:|---|---|
| `o` | Statics, being, locking, preservation | Статика, бытие, фиксация, сохранение |
| `a` | Action, modification, creation | Действие, изменение, создание |
| `u` | Counteraction, destruction, degradation | Противодействие, разрушение, деградация |
| `e` | Import: input, perception, reading | Ввод: вход, восприятие, чтение |
| `i` | Export: output, expression, emission | Вывод: выход, выражение, излучение |

**Example / Пример.** `LEL` = `l` space + `e` import + `l` location = «to come» (inbound movement toward a reference point) / «приходить» (движение к точке отсчёта). `JIP` = `j` society + `i` export + `p` object = «to give» / «давать».

## 2. Summary / Сводка

- EN: 150 roots in 11 domains; 36 palindromes (same domain and target). Process vowels: `A` 51, `E` 31, `I` 29, `O` 19, `U` 20.
- RU: 150 корней в 11 доменах; палиндромов 36 (одинаковые домен и цель). Гласные процесса: `A` 51, `E` 31, `I` 29, `O` 19, `U` 20.
- EN: 30 roots of the first list were revised against the axes (form, process or target); the former root is shown as «was». RU: 30 корней первого списка исправлены по осям (форма, процесс или цель); прежний корень указан как «was».
- EN: forms used in the README example are kept: `SIS` «give birth», `HOH` «think». RU: формы из примера в README сохранены: `SIS` «рожать», `HOH` «думать».
- EN: the README roots `NON`, `LIS`, `JOJ` are left free for their README meanings. RU: корни `NON`, `LIS`, `JOJ` из README оставлены свободными для их значений.

## 16. Verification / Проверка

- EN: all 150 roots match `C₁ V C₂` with a consonant `C₂`; all are unique; every root starts with the letter of its domain; the new roots do not coincide with any root of the earlier list in either its old or its revised form.
- RU: все 150 корней соответствуют `C₁ V C₂` с согласной `C₂`; все уникальны; каждый корень начинается с буквы своего домена; новые корни не совпадают ни с одним корнем прежнего списка ни в старой, ни в исправленной форме.
- EN: the fit of a root to its axes is a judgment, not a computation. Roots marked in the notes are the weakest. RU: соответствие корня осям это суждение, а не вычисление. Слабее всего корни с пометками в примечаниях.
